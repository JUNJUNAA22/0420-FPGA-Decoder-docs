# Archive

The archive is for obsolete but still useful design drafts, implementation
plans, and verification notes.

Do not use the archive for:

- current source-of-truth documentation;
- generated benchmark reports;
- generated vector bundles;
- simulator outputs;
- pytest temp directories;
- cache directories.

If a document still explains the current system, keep it under `architecture/`,
`specs/`, `plans/`, `development/`, or `verification/` instead of archiving it.
